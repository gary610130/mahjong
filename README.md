# 麻將帳本

打台灣麻將時記帳用的網頁 App：記每一把、自動算連莊加台和輸贏，保留每次牌局的戰績。

- 底／每台可設定（預設 50／20），自摸自動加 1 台，連 n 拉 n
- 組隊換手、重新抽位子、修改任何一把
- 個人數據、每場輸贏表、走勢圖，可依地點和月份篩選
- 資料存在 Firebase Firestore，同一個房間連結的人即時同步；離線也能記，連上網路後自動補傳

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面與操作 |
| `logic.js` | 計分邏輯（只靠設定和每一把的紀錄重算所有結果） |
| `firebase-config.js` | Firebase 網頁設定 |
| `firestore.rules` | 資料庫安全規則，要貼到 Firebase 主控台的 Firestore → 規則 |

## 房間

網址 `#` 後面的亂數就是房間碼。資料存在 `rooms/{房間碼}/games/{牌局}`，安全規則只開放這個路徑、而且不能列出所有房間，所以不知道房間碼就讀不到資料。房間連結只傳給牌友。
